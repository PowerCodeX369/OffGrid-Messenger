### Reading the history

Each version is an annotated Git tag on `main`. Inspect with `git show v1.4.11:firmware/main/main.c` or `git diff v2.5.3 v2.5.4 -- android/`. Component branches mirror the same source evolution, but are specialized, independent lines of commits and should not be merged blindly into `main`.
